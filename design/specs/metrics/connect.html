What do the other two services take?
GitHub
A token with repository read access, from Settings → Developer settings → Tokens. Traffic shows only for an account with write access to the repository.
App Store Connect
An API key (.p8 file), key ID and issuer ID, from Users and Access → Integrations. Sales and Trends read access is enough.
