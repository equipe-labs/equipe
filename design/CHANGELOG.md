# CHANGELOG

One line each: version · date · what · why · platforms affected. Version rules are in `README.md`'s governance.

- **2.0.0 (2026-11-10)** — Colour tokens take the desktop palette as shipped on `main` (T-699): a warm neutral `color.raw.warm.*` replaces the cool neutral and ink/bone alphas; accent `#2160AB`/`#7EB8F3`, status `work`/`wait`/`err` and every grey change value; tints are 8 % light / 12 % dark. New roles `color.side`·`side-hover`·`side-selected`·`popover`·`popover-hover`·`prose`·`text-soft`·`tooltip`·`on-tooltip`·`on-tooltip-muted`·`switch-on/off/knob`·`member-0…7`, components `sidebar.*`·`popover.*`·`tooltip.*`·`switch.*`, a `Desktop chrome` sheet. 206 contrast pairs, all AA. Why: the desktop palette was re-tuned after T-160 and the PM ruled that what is on screen is the reference; this lets `theme.rs` fill `Palette` from `tokens::palette()` with no visible change (map: `docs/t699-palette-map.md`). Affects: desktop none (values equal); site·iOS·Android see the change table in that doc when they adopt.
