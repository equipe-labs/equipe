## Whole
In all three options the eye flows from the large body title → the three cards → the file name at the top, and the core action, ‘return to the original context’, is pushed to the back. Instead of the reference's context preservation and consistent return rules, the sample document's large type and whitespace take the foreground, so it looks more like a presentation template than a product screen for long reports. ## Findings

[blocker] B·C · return label — ‘Back to conversation’ points to the wrong destination when the user entered from a board — show ‘Back to conversation’ or ‘Back to board’ depending on the entry context, wired to the same return action.

[blocker] C · two-line top header — the mode name takes the left side, while the return is scattered between the keyboard hint on the right and the × below — remove the separate mode strip and group a clickable return button with the Esc hint in the document header.

[blocker] A·B·C · state verification screens — a light 1200pt screen alone can't verify the required 760pt, 150% text, dark theme, long English title, and correct return — show those variants, scroll/selection/keyboard focus restoration before and after entry, and the Esc order with a popover open.
