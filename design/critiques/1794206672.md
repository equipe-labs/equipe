## Whole
The first glance splits between the long file name and the body title, then moves to the three large cards, and the return action is pushed behind them. On the 150% English screen in particular, the header takes about a quarter of the height, so it reads less as "a reading screen with a clear way back" and more as a screen where the title and tools area got bigger. There is plenty of whitespace but no density control to create a reading order, and with the logo covered it is a stock template that could sit in any document app.
