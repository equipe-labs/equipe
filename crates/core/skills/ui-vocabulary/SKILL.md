# A visual vocabulary

Shared words make feedback precise. When the person describes something loosely ("make it feel less busy", "that
popup thing"), map it to the terms below, say back what you understood in those terms ("fewer borders and more space
between the groups; the filter popover"), and use the same words in briefs, critiques and specs.

## Describing what you want

- **Name a reference and what to take**: "rows as dense as Linear's issue list", "a hero as calm as Stripe's" — a
  reference names a point where adjectives only name a region.
- **Place it on an axis**: dense ↔ airy, quiet ↔ loud, utilitarian ↔ editorial, sharp ↔ soft, serious ↔ playful,
  flat ↔ layered, monochrome ↔ colourful.
- **Point at the region**: "the second KPI tile", "the filter bar at 390", not "the page".

## Layout and structure

- **First screenful** — what shows before any scrolling at a given width ("above the fold").
- **Grid** — the columns and gutters content aligns to.
- **Gutter** — the space between columns; **margin** — the space between content and the screen edge.
- **Container** — a box that caps content width and centres it.
- **Measure** — the length of a line of text, in characters.
- **Whitespace** — empty space used on purpose to group, separate and rest the eye.
- **Rhythm** — repeated, predictable spacing that makes a page feel orderly.
- **Density** — how much information fits in a given area; compact versus comfortable.
- **Hierarchy** — the order in which the eye takes things in, set by size, weight, colour and position.
- **Visual weight** — how strongly an element pulls attention.
- **Alignment** — elements sharing an edge or a centre line; **optical alignment** — nudged so it looks aligned.
- **App shell** — the persistent frame of a product: sidebar, top bar, content area.
- **Sidebar** — vertical navigation on the side; **rail** — a narrow sidebar of icons.
- **Top bar / header** — the horizontal bar at the top with title, search or account.
- **Page header** — a page's title area with its context and primary action.
- **Split view / master–detail** — a list on one side, the selected item's detail on the other.
- **Inspector** — a side panel showing properties of the selected thing.
- **Card** — a bounded box grouping content about one thing.
- **Bento grid** — a grid of cards of mixed sizes, common on landing pages.
- **Section** — a full-width band of a landing page making one point.
- **Breakpoint** — the width at which a layout changes.

## Overlays and messages

- **Modal / dialog** — a window over the page that must be dealt with before going back.
- **Sheet** — a panel sliding up from the bottom (phones) or down from the top; **detents** — the heights it can rest at.
- **Drawer / side panel** — a panel sliding in from the side, leaving the page visible.
- **Popover** — a small floating panel anchored to its trigger.
- **Menu / dropdown** — a list of actions or choices that opens from a control.
- **Tooltip** — a small label shown on hover or focus.
- **Toast / snackbar** — a brief message that appears and leaves on its own.
- **Banner** — a persistent strip of page- or account-level news.
- **Callout / alert** — an inline box drawing attention to information.
- **Empty state** — what a view shows when there is nothing in it yet.
- **Skeleton** — a grey outline of content shown while it loads.
- **Spinner** — a looping indicator of indeterminate waiting; **progress bar** — shows how much is done.
- **Inline validation** — an error or confirmation shown next to a field.
- **Error summary** — a list of a form's errors at its top, linking to each field.

## Navigation

- **Tabs** — switch between peer views of the same thing.
- **Segmented control** — a compact row of two to five mutually exclusive options.
- **Breadcrumbs** — the trail of parent pages above a page title.
- **Command palette** — a search box (often `⌘K`) to jump anywhere or run any action.
- **Tab bar** — bottom navigation of a phone app with three to five destinations.
- **Navigation bar** — the top bar of a phone screen with title and back.
- **Stack / push** — moving deeper by sliding a new screen over the last one.
- **Stepper** — numbered steps of a multi-step flow; also a +/− control for small numbers.
- **Pagination** — splitting a long list into numbered pages; **infinite scroll** — loading more as you scroll.
- **Deep link** — a URL that opens a precise state: a tab, a filter, a record.
- **Anchor navigation** — links that jump to sections of the same page.

## Controls

- **Primary / secondary / tertiary button** — filled for the main action, outlined or tonal for others, text-only for
  the least.
- **Ghost button** — a button with no fill or border until hover.
- **Destructive button** — styled for irreversible actions such as delete.
- **Icon button** — a button showing only an icon, named for assistive tech.
- **Switch / toggle** — on or off, applied at once.
- **Checkbox** — select any number; **radio** — select exactly one.
- **Select** — a closed list of choices; **combobox** — a text field with a filtered list.
- **Chip / pill / tag** — a small rounded label, often removable or selectable.
- **Badge** — a small count or status marker on another element.
- **Avatar** — a person's or team's picture or initials.
- **Slider** — choose a value along a track.
- **Date picker** — a calendar for choosing dates; **date range** — a start and end with presets.
- **Inline edit** — editing a value in place, without a separate form.
- **Affordance** — a visual cue of how something can be used.

## Data

- **Data table** — rows and columns for comparing items across attributes.
- **Sticky header / column** — a header or first column that stays visible while scrolling.
- **Zebra striping** — alternating row backgrounds.
- **Tabular figures** — digits of equal width so numbers line up.
- **KPI tile / stat** — a key number with its label, period and comparison.
- **Delta** — the change against a previous value or target.
- **Sparkline** — a tiny line chart with no axes, inside a tile or a row.
- **Small multiples** — many small charts sharing one scale.
- **Legend** — the key to a chart's colours or marks; **direct labels** — names placed on the lines themselves.
- **Filter bar** — the controls above a list that narrow it; **facet** — one dimension to filter by.
- **Saved view** — a named set of filters, sort and columns.
- **Bulk action bar** — the actions that appear when several rows are selected.

## Visual style

- **Surface / layer** — a background level; raised surfaces sit above the page.
- **Elevation** — how high a surface appears, shown by shadow or lightness.
- **Hairline** — a 1px or thinner border.
- **Radius** — how rounded corners are.
- **Accent** — the one colour used for primary actions, selection and focus.
- **Neutrals** — the greys (often slightly tinted) that carry most of a screen.
- **Semantic colours** — colours for meaning: success, warning, danger, info.
- **Tint / shade** — a colour mixed with white / with black.
- **Gradient** — a blend between colours; **mesh gradient** — a soft multi-point blend.
- **Translucency / backdrop blur** — a surface letting a blurred background show through.
- **Grain / noise** — fine texture over flat colour.
- **Flat** — no depth cues; **skeuomorphic** — imitating physical materials.
- **Editorial** — magazine-like: large type, strong grid, generous space.
- **Brutalist** — raw, unpolished on purpose: system fonts, hard edges, visible structure.
- **Minimal** — few elements, much space, restrained colour.
- **Display type** — large type for headlines; **body type** — type for reading.
- **Serif / sans-serif / monospace** — type with strokes at the ends / without / with equal-width letters.
- **Weight** — how bold a typeface is; **tracking** — the space between letters; **leading** — the space between lines.
- **Type scale** — the fixed set of sizes a product uses.
- **Eyebrow** — a small label above a heading (overused by generated screens).
- **Lede** — the introductory paragraph under a headline.

## Motion and interaction

- **Easing** — how speed changes over an animation; **ease-out** — fast then slow.
- **Spring** — motion driven by physics, natural and interruptible.
- **Duration** — how long an animation lasts.
- **Stagger** — items animating one after another with a small delay.
- **Micro-interaction** — a small response to one action: a toggle flipping, a heart filling.
- **Hover / pressed / focus state** — how a control looks under the pointer, while pressed, when focused by keyboard.
- **Shared-element transition** — an element morphing from one screen into the next.
- **Scroll reveal** — content animating in as it scrolls into view.
- **Parallax** — layers scrolling at different speeds.
- **Scroll-jacking** — taking over normal scrolling; almost always a mistake.
- **Optimistic update** — showing the result before the server confirms it.
- **Haptics** — small vibrations confirming a touch action.

## Landing pages

- **Hero** — the first section: headline, subhead, call to action, product picture.
- **Call to action (CTA)** — the action a page asks for, usually a button.
- **Social proof** — evidence that others use and value it: logos, numbers, quotes.
- **Logo wall** — a row of customer logos.
- **Testimonial** — a customer's quote with name and role.
- **Feature grid** — features laid out in a grid of short blocks.
- **Pricing table** — plans side by side with prices and what each includes.
- **Comparison table** — the product beside alternatives, row by row.
- **FAQ accordion** — questions that expand to show answers.
- **Sticky CTA** — a call to action that stays visible while scrolling.

## Mobile

- **Safe area** — the part of the screen clear of the notch, status bar and home indicator.
- **Thumb zone** — the area one thumb reaches comfortably, mostly the lower part of the screen.
- **Large title** — an iOS top-level title that shrinks into the bar on scroll.
- **Swipe actions** — actions revealed by swiping a list row.
- **Pull to refresh** — dragging a list down to reload it.
- **Floating action button (FAB)** — Android's round button for a screen's main action.
- **Dynamic Type / font scale** — the system setting for text size apps should follow.
