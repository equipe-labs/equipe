# Taste

The person's taste for this design, a note a line. Read them before any proposal
and follow each; when a proposal departs from one, say which and why. A note the
person wrote or confirmed outranks one still waiting for their yes.
A note is `- <note> _(<where it came from>, YYYY-MM-DD)_` — from `the person`,
`sent back on T-12`, `answered on T-12` or `noticed on T-12`; the designer's
name the other tickets it was seen on (`seen on T-9 T-11`) and end in
`confirmed` once the person says so on the design screen.
Decisions, each with why, go in `decisions/`, a file each.
